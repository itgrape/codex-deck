# 容器端到端验证记录

验证日期：2026-11-20（Asia/Shanghai）。环境：macOS + OrbStack、Linux ARM64、Node.js 22、Codex CLI 0.170.0、cc-connect 1.5.2、Chrome。

使用独立镜像、容器和专用数据卷，映射到本机 3040 端口，没有使用开发服务的数据或真实账户凭据。镜像构建与容器管理通过 Docker CLI 执行，页面操作通过 Computer Use 完成。

## 修复

- 桥接异常退出后仍启用了随服务启动，但没有关闭入口：新增“关闭随服务启动”，已在失败状态下点击复测。
- 小屏旧样式隐藏头像，导致退出入口不可达：恢复头像，并调整页面标题与操作按钮布局，已实际退出验证。

## 验证范围

本地 MCP 和 OneBot 使用明确的测试端点，未向真实 IM 平台发送消息。未提供模型及 IM 平台凭据，因此没有验证真实模型生成内容、真实平台端到端收发，聊天和任务的流式完成、审批及变量传递另由可控子进程回归测试覆盖。Docker Hub workflow 已配置，本轮没有发布镜像。

## 清理
